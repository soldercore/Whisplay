# Privileged voice controls — isolated candidate, not deployed

Extends the existing helper and controls; no new daemon, menu, model, dependency, driver or storage format. Parent daemon: `4aa4479`; paired chatbot parent: `06133bc`.

Fixed privileged operations: Wi-Fi rescan only as a fallback when the ordinary user request fails, radio on/off, saved Wi-Fi UUID activation, visible-network join and Wi-Fi disconnect; start/restart only SSH, Ollama, Faster-Whisper and Piper; reboot/poweroff. Bluetooth retains existing unprivileged BlueZ operations and authorization. Read-only operations remain unchanged.

Safe radio enabling and service start execute immediately. Restarts, connectivity changes and power use the existing Cancel-first, expiring physical dialog after speech/app cleanup. The daemon drains the old PTT gesture and ignores unmatched releases; a new tap then new hold are required. Existing microphone ownership and four-tap escape are preserved.

The root helper blocks disruptive Wi-Fi operations and SSH restart when an established OpenSSH server socket is found, including IPv6/nonstandard ports. The daemon preflights this before closing GLaDOS; the helper rechecks at mutation. Unreadable state denies. This protects observed sessions, not arbitrary concurrent network administrators or a session established in the final check/action race. Radio on and SSH start stay available through the existing physical menus.

Wi-Fi profile activation/join/disconnect requires an independently timed 120-second NetworkManager checkpoint covering only Wi-Fi devices, with no destroy-other/delete-profile flags. Failure requests rollback; helper crash leaves the NetworkManager timer. Radio off is not claimed checkpoint-recoverable; it is SSH-blocked and recovered with the physical Network radio-on operation. New join profiles disable autoconnect, avoiding surprise activation after a failed join; existing profiles are never deleted. Credentials stay bounded stdin JSON/root-private temporary files, never argv/logs. See the [NetworkManager checkpoint API](https://networkmanager.pages.freedesktop.org/NetworkManager/NetworkManager/gdbus-org.freedesktop.NetworkManager.html).

The helper runs isolated system Python, only standard-library imports, fixed absolute binaries/environment/cwd, no shell, strict action/target validation, finite subprocess timeouts and a root-owned nonblocking operation lock. Capability discovery requires root-owned nonwritable real parent directories and helper protocol 2, so a legacy helper fails closed.

The existing explicit installer now validates root-safe parents/source/policy, refuses existing files/symlinks, installs exclusively owned files and removes only its own new files on failure. After separate approval: `sudo bash install_control_center_permissions.sh hamad`. It installs only `/usr/lib/whisplay/control-action` and `/etc/sudoers.d/whisplay-control-center`; no services/radios are changed. Incremental deployment must first back up actual code, helper/policy presence and user data; rollback restores code and removes only newly installed, hash-verified helper/policy files. Never replace broader sudoers files or stale memory.

Installed Pi discovery: NetworkManager 1.52.1 exposes checkpoint methods; Wi-Fi authorization is `no`/`auth` without a polkit agent. BlueZ permits ordinary user requests; real action authorization is not inferred. The helper is absent. The existing hamad administrator account already has `NOPASSWD: ALL`; this work does not grant or alter that policy and does not claim OS isolation against arbitrary code running as that administrator. Qwen remains restricted to the existing validated tool; the helper is not a sandbox against a compromised trusted host/administrator.

Development mutations are mocked. Actual RF recovery, permission installation, power and service mutations require separately approved deployment/acceptance. No physical latency claim is made; existing fast commands retain zero inference, one control RPC and no root capability subprocess. Original persona A/model/context/Whisper/Piper/memory/PTT are unchanged.
